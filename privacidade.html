Política de Privacidade

Dark Channel Studio, da S.A.L Sistemas LTDA. Vigente a partir de 2 de novembro de 2026.

1. O que é o Dark Channel Studio

O Dark Channel Studio é um aplicativo instalado no computador do usuário (Windows) que produz vídeos documentais e, quando o usuário autoriza, publica esses vídeos no canal do YouTube do próprio usuário. Não existe serviço em nuvem, conta de usuário ou servidor da S.A.L Sistemas LTDA envolvido no funcionamento do aplicativo.

2. Dados do Google que o aplicativo acessa

Ao conectar a sua conta do Google, o aplicativo pede autorização (OAuth 2.0) para os seguintes escopos do YouTube:

  • youtube.upload: enviar vídeos ao seu canal.
  • youtube.force-ssl: definir título, descrição, miniatura, legendas e traduções dos vídeos que o aplicativo enviou.
  • youtube.readonly: ler o nome do canal e os dados dos vídeos enviados, para confirmar o que foi gravado.
  • yt-analytics.readonly: ler visualizações, tempo assistido e métricas semelhantes dos vídeos enviados, para exibi-las no aplicativo.

O aplicativo não lê e-mails, contatos, arquivos do Google Drive, comentários ou qualquer outro dado da sua conta.

3. Como os dados são usados

Os dados obtidos do Google são usados exclusivamente para publicar os vídeos que você aprovou e para mostrar, dentro do aplicativo, o resultado dessa publicação e o desempenho dos vídeos. Nenhum envio ao YouTube acontece sem a sua aprovação explícita na tela do aplicativo.

4. Onde os dados ficam

As credenciais de acesso (o cliente OAuth e o token de autorização) ficam armazenadas apenas no seu computador, cifradas com a proteção de dados do Windows (DPAPI) e vinculadas ao seu usuário do Windows. As métricas lidas ficam no banco de dados local do aplicativo. Nenhum desses dados é enviado à S.A.L Sistemas LTDA nem a terceiros.

5. Compartilhamento

O aplicativo não vende, aluga ou compartilha dados do usuário com ninguém. Os únicos destinatários dos dados são os próprios serviços do Google (YouTube Data API e YouTube Analytics API), para executar o que você pediu.

6. Uso limitado dos dados do Google

O uso e a transferência, pelo Dark Channel Studio, de informações recebidas das APIs do Google seguem a Política de Dados do Usuário dos Serviços de API do Google, inclusive os requisitos de Uso Limitado.

7. YouTube

O aplicativo utiliza os Serviços de API do YouTube. Ao usá-lo, você também concorda com os Termos de Serviço do YouTube e com a Política de Privacidade do Google.

8. Como revogar o acesso

Você pode desconectar a conta a qualquer momento pelo botão Desconectar nas configurações do aplicativo, o que apaga o token do seu computador. Também pode revogar a autorização diretamente no Google em myaccount.google.com/permissions. Desinstalar o aplicativo e apagar a pasta de dados remove todas as informações armazenadas localmente.

9. Retenção

Os dados ficam no seu computador pelo tempo que você quiser. O aplicativo não mantém cópias fora dele.

10. Alterações

Mudanças nesta política serão publicadas nesta página, com a data de vigência atualizada.
